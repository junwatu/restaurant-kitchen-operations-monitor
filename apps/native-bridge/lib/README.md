# Runtime JARs (not committed)

Place these four files here:

- `gridstore.jar`
- `gridstore-arrow.jar`
- `gridstore-advanced.jar` (licensed Cloud JAR, from the Cloud download)
- `arrow-memory-netty.jar`

Use `npm run setup:mac` for the public JARs and `npm run install:cloud-jar -- <rpm-or-jar>` for the licensed one. Do not publish the licensed JAR.
